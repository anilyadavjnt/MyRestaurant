# MyRestaurant – iOS App

MyRestaurant is an iOS application developed to provide users with a convenient restaurant browsing and food ordering experience.

## Features
- Restaurant and food listing
- Clean and user-friendly interface
- Easy navigation between app screens
- Restaurant-focused user experience

## Tech Stack
- **Language:** Swift
- **Platform:** iOS
- **IDE:** Xcode
- **UI:** UIKit / Storyboard *(if used in the project)*

## Getting Started
1. Clone this repository.
2. Open the `.xcodeproj` or `.xcworkspace` file in Xcode.
3. Select an iOS Simulator or a connected device.
4. Build and run the project.
